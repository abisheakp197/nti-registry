What This Is

Unlike PyPI, npm, or awesome-lists, every entry in this registry requires cryptographic proof:

  • Dilithium5-signed by the tool owner
  • Cross-verified against a live nti-badge node
  • Machine-readable for AI agent discovery
  • Offline-verifiable forever
  • Federated — anyone can mirror
